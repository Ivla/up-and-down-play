# Up&Down

10x10 的棋盤，每個格子不是升起就是下沉。從左下角 (1,1) 走到右上角 (10,10)。

**[點此遊玩](https://ivla.github.io/up-and-down-play/)**

## 玩法

- 每次只能走到上下左右相鄰、而且升起的格子。
- 每走一步，落腳格上下左右四格會在升起和下沉之間切換，落腳格本身不變。
- 有人站著的格子和起點格不會下沉。
- 用滑鼠點格子，或按 W A S D 移動。
- 「回到上一步」退回一步，「從頭開始」重來。

## 模式

- **單人遊戲**：從 (1,1) 走到 (10,10)。
- **單人遊戲含敵人**：兩隻敵人在你每走一步時也跟著走一步，同樣會翻轉格子。被碰到就退回起點。
- **單人對戰 AI** 和 **雙人遊戲**：1P 從 (1,1) 出發，2P 從 (10,10) 出發，各自走到對角。輪流行動，每回合選一個：
  - 移動一步
  - 攻擊：點選相鄰的對手，對手退回他的起點
  - 返回上一步：回到上一格
- 單人對戰 AI 開始前可選擇難度：簡單、普通、困難。
- 雙人遊戲建立房間後，另一位玩家輸入 4 位數的房間號碼加入。
